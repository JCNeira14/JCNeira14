## Featured project

### [PC First Boot Assistant](https://github.com/JCNeira14/pc-first-boot-assistant)

A personal, learning-focused project that uses stateful RAG to guide the diagnosis of a newly assembled PC. It retrieves technical documentation, asks targeted follow-up questions, and proposes one safe next step at a time.

- Two-step RAG over a local, versioned knowledge base built from official technical sources.
- LangGraph state, conditional routing, checkpoints, and human-in-the-loop approvals.
- Deterministic safety gates and citation validation outside the model prompt.
- Offline tests for retrieval, routing, interruptions, and safety rules.

**Stack:** Python · LangChain · LangGraph · Pydantic · Gemini/OpenAI · RAG
